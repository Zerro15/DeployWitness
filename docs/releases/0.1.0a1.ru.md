# DeployWitness 0.1.0a1 — краткое описание alpha

> Черновик для проверки. Релиз не опубликован.

DeployWitness — ранняя local-first alpha для сравнения изменений Docker Compose и объяснения нарушений поддерживаемых контрактов с помощью детерминированных статических свидетельств.

В alpha входят CLI для одного Compose-файла и сравнения base/head, отчёты text/Markdown/JSON со статусами `PROVEN_CONFIG_BREAK`, `POTENTIAL_RISK`, `UNKNOWN` и ограниченным `NO_FINDING`; начальная модель сервисов, зависимостей, сетей, mounts и выбранных переменных окружения; reusable GitHub Actions workflow, который читает PR как Git blobs, не checkout-ит и не запускает код PR и публикует Markdown job summary на runner владельца репозитория.

Это pre-1.0 версия: интерфейс CLI и формат witness могут измениться. Полная Compose Specification, объединение overrides, `.env`, интерполяция и profiles не поддерживаются. Статическое свидетельство подтверждает только нарушение поддерживаемого конфигурационного инварианта, но не runtime-аварию и не потерю данных. `NO_FINDING` охватывает только реализованные правила. Fork PR ещё не проверен E2E. Пакет PyPI и комментарии в PR отсутствуют.
