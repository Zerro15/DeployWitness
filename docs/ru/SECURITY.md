# Безопасность

[English](../SECURITY.md) | [Русский](SECURITY.md) · [Индекс документации](README.md)

DeployWitness локально анализирует недоверенные конфигурации. У него нет сервера анализа, телеметрии, доступа к Docker socket или исполнения кода в стандартном режиме. После установки Python-зависимостей анализ не выполняет сетевых запросов.

YAML разбирается безопасным loader с ограничениями размера файла, числа узлов, глубины вложенности и количества сервисов. Повторяющиеся ключи и небезопасные YAML-теги отклоняются. Инструмент не выполняет интерполяцию Compose и не читает `.env` или production-секреты. Значения переменных окружения используются только в памяти для сравнения; значения и хеши не попадают в отчёт. Пути bind mounts и имена сетей могут быть чувствительными.

Если парсер не может учесть поведение Compose, результатом будет `UNKNOWN`. Не считайте `NO_FINDING` гарантией безопасности деплоя. Воспроизведение runtime-ошибок пока не реализовано.
