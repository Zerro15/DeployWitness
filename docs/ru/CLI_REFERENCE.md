# Справочник CLI

[English](../CLI_REFERENCE.md) | [Русский](CLI_REFERENCE.md) · [Индекс документации](README.md)

Исполняемая команда называется `deploywitness`. Ниже описан CLI текущей alpha-версии.

## `check`

Сравнить два явных Compose-файла:

```text
deploywitness check --base BASE --head HEAD [--format text|json|markdown]
```

- `--base` — базовый YAML-файл.
- `--head` — кандидат на замену.
- `--format` — необязательный формат отчёта; по умолчанию `text`.

Инструмент не определяет Git-ревизии, не объединяет Compose overrides и не выбирает profiles. Если итоговую конфигурацию нельзя надёжно определить, появится `UNKNOWN`, а команда завершится кодом `3`.

## `scan`

Найти и разобрать Compose-файл без базового состояния:

```text
deploywitness scan [PATH] [--file FILE]
```

`PATH` по умолчанию — текущий каталог. Без `--file` команда ищет в нём файлы с именами `compose.yaml`, `compose.yml`, `docker-compose.yaml` и `docker-compose.yml`. Если найдено несколько, инструмент сообщает `UNKNOWN` и просит выбрать один файл. Опция `--file` указывает проверенный YAML явно.

`scan` показывает число сервисов и неразрешённые условия парсера. Это не сравнение изменений и не заключение о безопасности.

## Остальные команды

- `deploywitness rules` — список реализованных идентификаторов правил.
- `deploywitness version` — версия пакета.
- `deploywitness --help` и `deploywitness check --help` — справка CLI.

## Коды завершения

| Код | Значение |
| --- | --- |
| `0` | Доказанного нарушения нет. Риски возможны; `NO_FINDING` относится только к реализованным правилам. |
| `2` | Найдено хотя бы одно `PROVEN_CONFIG_BREAK`. |
| `3` | Ввод некорректен, анализ не разрешён или результат содержит `UNKNOWN`. |

Если одновременно есть доказанное нарушение и `UNKNOWN`, текущий CLI возвращает код `2`. Изучите полный отчёт, чтобы увидеть оба результата.

## Форматы отчёта

`text` — стандартный вывод в терминал. `markdown` удобно публиковать в сводке CI или сохранять как артефакт. `json` содержит `schema_version` и структурированные поля свидетельства. Сейчас используется схема версии `1`; до `1.0.0` она может измениться.

См. [Failure Witness](FAILURE_WITNESS.md) и [CI-интеграции](CI_INTEGRATIONS.md).
