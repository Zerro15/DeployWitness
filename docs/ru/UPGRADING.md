# Обновление DeployWitness

[English](../UPGRADING.md) | [Русский](UPGRADING.md) · [Индекс документации](README.md)

DeployWitness ещё не достиг версии 1.0. Считайте обновления потенциально несовместимыми и читайте release notes перед сменой закреплённого commit или версии пакета.

## Пользователям GitHub Actions

Обновляйте ссылку reusable workflow и параметр `deploywitness_ref` одновременно на один и тот же проверенный полный SHA длиной 40 символов. Прочитайте release notes и запустите известный безопасный сценарий и сценарий с нарушением контракта в тестовом PR. Результат находится в summary запуска workflow; комментарий в PR не создаётся.

## Пользователям Python-пакета

При смене alpha-версии создайте чистое окружение, установите выбранный wheel или checkout исходников и выполните `deploywitness version`. Не считайте JSON-схему witness стабильной до версии 1.0. Сейчас миграция не требуется; сохраните старые отчёты, если они нужны для аудита.
